# TandOrbit 使用与验收

## 首次使用

在两台电脑上连接同样的两台显示器，并开启显示器的自动输入选择。从「设置 → 开始使用」点「去配对」，在两台电脑上都打开「查找附近电脑」。任一端选中另一台电脑后，两边都会弹出六位数字。看到相同的数字后，在两边分别确认。配对使用局域网，两台电脑连通后可在「开始使用」点击「开始检查」。

搜索窗口列不出另一台电脑时，可展开「手动配对」。在两端分别复制本机配对信息，粘贴到另一端，并对照显示的设备指纹后确认。

在两端的「显示器」分别选中同一物理主屏和副屏，并保存设置。默认共享时 Mac 使用主屏、Windows 使用副屏。若要从 Mac 唤醒 Windows，在 Windows 的「两台电脑 → 网络与配对详情」选择支持网络唤醒的网卡，再与 Mac 重新配对。Windows 默认端口为 5000，Mac 默认为 5001。

## 切换与共享

| 操作 | 快捷键 |
|---|---|
| Mac 双屏 | Ctrl + Alt（Option）+ 1 |
| Windows 双屏 | Ctrl + Alt（Option）+ 2 |
| 双机共享 | Ctrl + Alt（Option）+ 3 |
| 收回本机键鼠 | Ctrl + Alt（Option）+ Esc |

主窗口高亮的是已确认的用屏方式。切换失败时，窗口会显示阶段和原因。在两端「键鼠与剪贴板」都开启键鼠共享，并选择键鼠实际连接的那台电脑。把指针推向指定边缘可操作另一台电脑。把指针推回进入时的边缘，或按收回键，即可返回本机。两台电脑都开启文字同步后，共享模式中新复制的纯文本会发到另一台。

## 常见问题

- **配对但仍离线**。检查两端是否使用同一版本、都导入了对端信息，并允许专用网络访问监听端口。
- **显示器绑定失效**。在两端各点「重新检测显示器」并检查物理屏对应关系。相同型号的屏幕以系统报告的设备标识区分。
- **Mac 无法释放指定屏幕**。检查 BetterDisplay 及其 CLI 是否可用，并确认当前安装具备单屏断开与重连能力。
- **键鼠共享未就绪**。检查两端是否选了同一台连接键鼠的电脑、macOS 是否已授予辅助功能与输入监控权限，以及桌面是否已解锁。接收端的高权限窗口由系统限制。
- **切换待恢复**。让两台电脑回到同一局域网并保持应用打开。在托盘查看操作 ID 和失败阶段。需要立即看到本机桌面时，点击「恢复本机显示」。
- **音频未切换**。在「音频」刷新设备，重新选择所需端点，或打开系统声音设置。

## 实机发布验收

按 Mac → Windows → 共享 → Mac 验证一轮，再按反向验证一轮。检查两台物理显示器的信号源和分辨率、双屏排列、WoL 到 Agent 可达的时间、显示器拔线重连、双机同时发起切换、跨屏时拖动及修饰键释放、两端锁屏和重新配对。分别检查支持 BetterDisplay 和需要手动处理共享的环境，并在 Windows 验证原生拓扑和兼容后端。

# TandOrbit 使用与验收

## 首次使用

在两台电脑上连接同样的两台显示器，并开启显示器的自动输入选择。两端启动 TandOrbit 后，在「设置 → 连接」分别复制本机配对信息，粘贴到另一端。对照屏幕上的指纹后确认。设置中显示「已配对」代表本机已保存设备身份，主窗口的对端指示灯反映认证连接状态。

在两端的「显示器」分别选中同一物理主屏和副屏。建议先保留默认共享角色，Mac 使用主屏、Windows 使用副屏。若 Windows 网卡支持网络唤醒，在 Windows 端选定 WoL 网卡后再复制配对信息。Windows 默认监听 5000，Mac 默认监听 5001。

## 切换与共享

| 操作 | 快捷键 |
|---|---|
| Mac 双屏 | Ctrl + Alt（Option）+ 1 |
| Windows 双屏 | Ctrl + Alt（Option）+ 2 |
| 双机共享 | Ctrl + Alt（Option）+ 3 |
| 收回本机键鼠 | Ctrl + Alt（Option）+ Esc |

主窗口高亮的是已提交的模式。切换失败时，窗口会显示阶段和原因。键鼠需要两端启用，并配置同一台主控机。把指针推向配置的边缘可转交控制，返回进入边缘或按收回键可返回本机。两台电脑都允许文本剪贴板后，新复制的纯文本才会从其中一端发送。

## 常见问题

- **配对但仍离线**。检查两端是否使用同一版本、都导入了对端信息，并允许专用网络访问监听端口。
- **显示器绑定失效**。在两端各点「刷新」并检查物理屏对应关系。相同型号的屏幕以系统报告的设备标识区分。
- **Mac 无法释放指定屏幕**。检查 BetterDisplay 及其 CLI 是否可用，并确认当前安装具备单屏断开与重连能力。
- **键鼠共享未就绪**。检查两端主控设置、macOS 辅助功能与输入监控、当前桌面是否已解锁。接收端的高权限窗口由系统限制。
- **切换待恢复**。让两台电脑回到同一局域网并保持应用打开。在托盘查看操作 ID 和失败阶段。需要立即看到本机桌面时，点击「恢复本机显示」。
- **音频未切换**。在「音频」刷新设备，重新选择所需端点，或打开系统声音设置。

## 实机发布验收

按 Mac → Windows → 共享 → Mac 验证一轮，再按反向验证一轮。检查两台物理显示器的信号源和分辨率、双屏排列、WoL 到 Agent 可达的时间、显示器拔线重连、双机同时发起切换、跨屏时拖动及修饰键释放、两端锁屏和重新配对。分别检查支持 BetterDisplay 和需要手动处理共享的环境，并在 Windows 验证原生拓扑和兼容后端。
